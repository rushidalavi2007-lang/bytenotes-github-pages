ABOUT BYTENOTES

A small blog about learning technology.

ByteNotes is a simple student project built to share coding notes, project experiences and useful things learned along the way.

Learn → Build → Share

Every article tries to turn a lesson into something practical. Read it, try the small challenge, and build something of your own.

Built with

HTML, CSS and vanilla JavaScript. There is no backend or database, so the site can be hosted directly with GitHub Pages.
