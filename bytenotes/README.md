# ByteNotes

A simple student blog built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive homepage
- Featured article
- Blog listing
- Search
- Category filters
- Individual article pages
- No backend or database
- GitHub Pages ready

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `bytenotes`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your URL will look like:
`https://YOUR-USERNAME.github.io/bytenotes/`

## Add a new post

1. Create a new HTML file inside `posts/`.
2. Add its details to `js/posts.js`.
3. Add an image or replace the text cover with your own design.
4. Commit and push to GitHub.
